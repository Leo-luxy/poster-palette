# 执行计划简明说明

这份计划要回答两个问题：**1950—2025 年，全球电影样本的海报配色整体怎样变化？2001—2025 年，不同国家／地区组的海报配色有什么差异？** 各组保留实际样本构成，直接呈现配色面貌和差异大小。

我会使用现有的 19,694 部电影配色数据，结合各颜色的占比和三个指标：明度（画面亮不亮）、饱和度（颜色鲜不鲜）、色彩丰富度（整体色彩是否丰富）。直观图使用完整样本汇总的色相分布，指标图说明明暗和鲜艳程度。

具体要做以下四件事：

1. **整理出可比较的数据。** 将电影年份、制片国家与配色记录对应起来，保证一部电影只占一行。缺少国家信息的电影仍可用于时间分析。

2. **画出全球配色随上映年代的变化。** 时间分析使用全部国家的电影，不区分国家，也不排除缺少国家信息的电影。按年代展示颜色占比条，再用指标趋势说明变化方向和幅度。

3. **比较七个国家／地区组的配色。** 使用 2001—2025 年的美国、英国、法国、意大利、日本、华语组、韩国电影。合拍片按参与制片国家与原语言规则推定归属。每组一行颜色占比条，再用指标图比较差异大小。这个年份和国家筛选只用于空间分析。

4. **把结果整理成图、表和解释。** 每个核心结论都说明样本范围、差多少、估计有多确定，并保存分析代码和结果表，方便复核与重新生成。

报告保留两张组合图：**图 2 展示全球时间变化，图 4 展示 21 世纪空间差异**。每张包含“色相分布＋指标”，详细数值放表中，不再另外增加重复图。

PPT 最多四页，直接拆用报告中的图面：

| 页次 | 内容 | 作用 |
| --- | --- | --- |
| 1 | 全球年代色相分布 | 直观看各种颜色的占比怎样变化 |
| 2 | 全球明度、饱和度趋势 | 看整体变亮还是变暗、变鲜艳还是变灰淡 |
| 3 | 七组国家／地区色相分布 | 直观看 21 世纪的空间配色差异 |
| 4 | 七组明度、饱和度对比 | 看差多少，以及估计有多确定 |

PPT 优先讲容易理解的明度和饱和度，丰富度仍保留在报告同组图中。报告与 PPT 复用同一批结果，形成两组分析、四个主要图面，不额外扩充图表。

海报缩略图原本是帮助理解的示例，但不能代表整个组，也会占用篇幅。本轮去掉海报墙，直接展示完整样本的颜色分布。

图表保持简明：图内只留必要标签、每组一次样本量和共用图例，时间趋势只画一条线及一层分布带。计算细节和完整数值放正文或附表，让读者先看清配色和变化。

解释结果时要守住两个边界：我们知道的是电影上映年，无法确认海报设计年；国家归属是按规则推定，无法证明海报由哪里设计。因此，最终回答的是现有样本中的变化与差异，不能直接把它们认定为审美演变或国家文化造成的结果。
