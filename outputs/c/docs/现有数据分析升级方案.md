### 3.3 通用输出格式

- 表格 UTF-8、固定列名、稳定排序。逐片表主键为 `id`，长表须定义复合主键。
- 无定义的量用空值，不以 0 代替；比例为 0 必须表示确实未出现。
- 独立有效性使用独立标记，例如 `pair_hue_valid`、`pair_delta_e_valid`、`spatial_valid`、`warmth_valid`。
- 逐片表保留失败状态；合并后仍覆盖全部母样本，不因某模块缺失删除电影。
- 组统计统一包含 `dimension, group, metric, n_total, n_valid, mean, median, q1, q3, p10, p90, mean_ci_low, mean_ci_high`。
- 任何只在有效子集上计算的指标，组统计必须同时报告 `n_valid / n_total`；有效率在组间差异明显时，图注写明比较的是有效子集。

## 4. c06：主辅色、共现与冷暖

### 4.1 主色来源与解释边界

`dom1..3`、`ds1..3` 来自 `scripts/03_features.py`：只对 **S ≥ 0.20 的像素**（最多随机抽 3,000 个）做 RGB K-Means，k 固定为 3，按簇大小排序。因此：

- 「主色／辅色」指**有色像素中的前两大簇**，不是整张海报面积最大的两种颜色；黑底、白底等低饱和区域不参与。`secondary_share` 是有色像素内的份额，不是全图份额。
- 掩膜只看 S，不看 V：近黑但带色偏的像素会进入聚类。当前数据中 42% 的 `dom1` 明度 < 0.20，其色相不可靠。
- k 固定为 3 会把同一色相按明暗拆成多簇。当前 60% 的电影前两主色夹角 < 30°（中位数约 20°）。夹角主要反映「同色系明暗分层 vs 异色搭配」，不能直接解读为配色理论中的互补或对比关系。

### 4.2 主色解析与颜色转换

校验 `dom1..3` 为合法 HEX，`ds1..3` 有限、非负且总和大于 0；先归一化份额。固定使用 sRGB→XYZ→Lab、D65 白点，颜色转换封装成一个向量化实现。HSV 的 H 用角度，S、V 为 0—1。

逐片输出 `relations.csv`：

| 字段 | 定义 |
| --- | --- |
| `dom{1..3}_h/s/v/l/a/b` | 三个主色的 HSV、Lab |
| `secondary_share` | 归一化后的 `ds2` |
| `pair_hue_gap_deg` | `min(abs(h1-h2), 360-abs(h1-h2))`，0—180 |
| `pair_delta_e76` | 前两主色的 Lab 欧氏距离 |
| `primary_hue_bin, secondary_hue_bin` | 0—11 的色相扇区 |
| `primary_class14, secondary_class14` | 暗色、低饱和色与 12 色相类别 |
| `warmth_30, warmth_15, warmth_45` | 三种轴向的余弦冷暖投影 |
| `pair_hue_valid, pair_delta_e_valid, warmth_valid, status` | 有效性与异常状态 |

`pair_hue_valid` 要求两个主色 S、V 均达到阈值且辅色份额达标；`pair_delta_e_valid` 只要求两个主色存在且辅色份额达标。

14 类顺序固定为 `dark, neutral, h0..h11`：先判 V < 0.20 为 dark，再判 S < 0.20 为 neutral，其余按 30° 分箱。该顺序全项目共用。

### 4.3 共现矩阵

- **主矩阵为 14 类**：覆盖所有主色有效的电影，dark／neutral 单列，不丢弃暗色海报。
- 12 类矩阵只在 `pair_hue_valid` 子集上计算，作为补充。该子集会系统性排除暗色海报，而海报整体随时间变暗，因此各组有效率不同；图注必须标出每组 `n_valid / n_total`，不与 14 类结果混读。
- 主版本按**无序色对**计数（`{a,b}` 与 `{b,a}` 合并，14 类共 105 格）。国家组样本约 200—1,000，有序 196 格过于稀疏。有序矩阵仅对时间维度输出，作为补充。
- 对每个年代、国家组输出完整格子，包括零计数格。
- `cooccurrence.csv` 字段：`dimension, group, matrix_kind, ordered, class_a, class_b, n_pair, n_valid_movies, joint_probability`。
- `joint_probability = n_pair / n_valid_movies`，每组矩阵和为 1；无有效电影则全为空值。
- 时间参照为全部时间有效电影合并矩阵；国家参照为七组各自归一化矩阵的等权平均。国家差值图对所有组使用同一参照，保存组权重与有效n，不计算无平滑的稀疏倍数排名。

图面优先联合概率与参照差值热力图，跨组共用类别顺序和色标；单格 `n_pair < 5` 标记低支持。禁止从组平均 hue 直方图反推主辅色共现。

### 4.4 冷暖投影

已有 `h0..h11` 非负有限、总和正且 `sat_frac ≥ 0.10` 时，逐片归一化为 p。计算：

`warmth_alpha = sum(p[k] * cos(radians((k + 0.5) * 30 - alpha)))`

主轴 alpha=30°，另算 15°、45°。保留全部三列，不对不稳定结果选择性换主轴。接近 0 只解释为投影接近 0（例如冷暖色份额相抵），不自动解释为低饱和或无冷暖。

## 5. c07：单轮图像处理

### 5.1 预处理与缓存

按 ID 定位 `data/posters/<id>.jpg`。统一 RGB，裁切 `(0, 0, width, int(height * 0.88))`，BICUBIC 缩放到 120×160。HSV 按既有 Pillow 转换口径取值：H×360/255，S、V 除以 255；Lab 由同一 RGB 图计算。

每片一次读取并计算全部分支。缓存写入 `outputs/c/cache/advanced/`，以压缩 npz 保存逐片记录和 45×64 的 V、S 网格；缓存键为海报文件 SHA-256 + 像素处理配置。`--resume` 只复用键一致的缓存。

缺图、坏图等写 `image_audit.csv`，状态区分 `missing_file, decode_error, invalid_pixels`；汇总阶段保留对应 ID 和缺失字段。

### 5.2 空间字段

九宫格按行优先编号 `r0c0`—`r2c2`，边界用整数等分，所有像素恰好归属一格。

`spatial_features.csv` 每片一行，包含：

- 每格 `grid_r{r}c{c}_v/s/color_fraction`。
- `center_edge_v/s`：独立中心框均值减外围均值；中心宽高各为 √0.5，记录整数像素化后的实际面积比例。
- `top_bottom_v/s`：上三分之一减下三分之一；`left_right_v/s`：左三分之一减右三分之一。分区按原始像素面积汇总，前项减后项。
- `left_right_delta_e76`：三对左右镜像格 Lab 均值色差的平均，保留各对明细。
- `v_p10, v_p50, v_p90, v_skew, lab_a_mean, lab_b_mean`；常数明度图偏度记缺失。
- `vivid_frac`：S > 0.70 且 V > 0.50 的像素占全图比例。

解释边界：

- 底部12%已裁掉，处理后图的下三分之一对应原图从顶部约58.7%—88%的区域，仍可能含片名。`top_bottom_*`混有标题排版效应，不能只解读为画面构图。
- 中心半面积与九宫格中心格分开保存。左右 ΔE 命名为颜色不平衡指标，不命名为语义对称性。

### 5.3 空间数值网格

从处理后 V、S 数值阵列以 Pillow 浮点模式 F、BOX 重采样缩放为宽45×高64，数组统一为 `(64,45)`、float32。按电影等权汇总，输出组均值、中位数、标准差和逐格有效 n，存为 `spatial_maps.npz`；`spatial_maps_index.csv` 记录维度、组、指标、数组键和支持。

同一指标所有组共用色标。热力图不平均 RGB、不做人物对齐，不从单片抽象配色图生成。

## 6. c08：分组、分布与对比

先按 ID 连接 relations、spatial；连接必须一对一。复用固定时间与国家样本，按模块有效性汇总，不全表完整案例删行。

产物契约：

| 文件 | 内容 |
| --- | --- |
| `group_summary.csv` | 通用分组统计，补充 `p90_p10, iqr` |
| `tail_thresholds.csv` | `dimension, metric, reference_n, threshold_p10, threshold_p90` |
| `tail_shares.csv` | `dimension, group, metric, n_valid, low_n, middle_n, high_n, low_share, middle_share, high_share` |
| `advanced_contrasts.csv` | `dimension, group_a/b, metric, contrast_kind, estimate_kind, estimate, ci_low/high, n_a/b, reference_scope, weight_policy, comparison_family` |
| `standardization_reference.csv` | `dimension, metric, reference_scope, weight_policy, n_valid, n_groups, mean, sd`；森林图使用的共同尺度 |
| `country_reference_weights.csv` | `feature_set_or_metric, group, n_valid, group_weight, per_movie_weight`；国家共同参照的权重记录 |
| `lab_mean_bootstrap.csv` | `group, replicate, n_joint, lab_a_mean, lab_b_mean`；同一电影重抽样中的二维均值，供冷暖图均值置信椭圆使用 |
| `coverage.csv` | 各模块／组／类型／时段的有效数、排除数与原因 |

时间阈值从全部时间样本一次计算；国家阈值从七组等权混合分布一次计算：每组权重1/7、组内每片权重1/(7*n_g)。加权分位数定义为排序后累计权重首次达到目标分位点的观测值。固定 `low: x < P10`、`high: x > P90`、其余为 middle，保存相等值数量；不得按组另设阈值。

时间保留两组预定年代对比；国家输出全部21对均值差，组对按固定代码顺序取a减b，符号仅为存储方向，不表示优劣或中心地位。新增指标列表在配置中冻结。差值用电影级bootstrap 1000次、百分位区间。

国家另输出 `contrast_kind=deviation_from_equal_group_mean`：`delta_g = mean_g - sum(mean_h)/7`，`group_b=ALL7_EQUAL`。每次在七组内分别重抽样一次，用同次的七组均值计算共同参照和七个偏离，保留自包含参照的协方差；不能把共同参照当成与该组独立的样本。此偏离表示相对统计中心的位置，不表示离某种标准的差距。

区间均为逐项区间，不提供多重比较下的同时覆盖保证，结论按效应量大小陈述，不按「区间是否跨0」逐项宣布显著。小提琴／山脊图同指标使用一致带宽；有边界指标限定显示范围并与原始分位数核对。

为绘图补充保存的尺度与二维均值，均在现有汇总／bootstrap循环中输出，不新增重抽样轮次。Lab二维均值使用a*、b*同时有效的电影，两个坐标必须使用同一组重抽样ID，不能拼接独立抽样结果。

## 7. 已移除：独特性与反馈模型

原 c09（类型内 kNN 独特性 + 评分／票数回归 + 训练／测试预测）整体移除，原因：

1. 不属于时间／国家两个问题，配色与评分的关系已由图 3 回答（相关系数在 ±0.08 内）。
2. 样本按「每年票数前 2.6%」入选，以 `vote_count` 为结果变量等于在结果上做了截断筛选，系数有选择偏差。
3. 样条、交互、预测指标在主效应接近 0 的前提下属于过度检验。

## 8. c09：多维总览与趋近

### 8.1 固定特征集合

基础集 9 项：`mean_v, mean_s, colorful, v_std, pair_delta_e76, center_edge_v, top_bottom_v, left_right_delta_e76, vivid_frac`。

扩展集在基础集上加 `pair_hue_gap_deg, warmth_30`。按单套完整案例报告覆盖；基础集不因纯灰画面而主动排除，但原主色缺失等仍产生缺失并记录。

先删除零方差列，报告相关性矩阵并标出 |r| > 0.8 的列对。每套特征按场景固定一个参照：时间模型在全部时间样本完整案例上每片等权拟合；国家模型在2001—2025七组完整案例上按组等权拟合。国家的所有时期和组画像复用同一国家模型，不按国家或时期重新拟合。

共同缩放公式为 `mu=sum(w_i*x_i)`、`sd=sqrt(sum(w_i*(x_i-mu)^2))`，权重和为1，采用总体矩口径；时间权重为1/N，国家权重为1/(7*n_g)。实际n_g、有效ID和权重保存到模型元数据，零SD列移除并记录。国家和时间模型是两个坐标系，不直接比较两套模型的PC坐标值。

### 8.2 画像与 PCA

- 画像热力图从对应场景共同尺度下的组均值生成，保存n；国家零点为七组均值的等权中心，不由最大样本组定义。
- PCA采用显式加权SVD：标准化后构造 `sqrt(w_i)*z_i`，由SVD得到载荷；逐片得分为 `z_i @ components.T`。不能只对缩放做加权而仍用普通逐片PCA，否则大样本国家仍会主导方向。
- 国家图的原点为当前特征集七组等权中心。保存 `pca_scores.csv, pca_loadings.csv, pca_variance.csv, scaler.json, pca_reference_weights.csv`，记录 `model_scope=time_movie_equal/country_group_equal`。
- 图中所有国家用相同大小的组均值点，组内分布用相同采样数的背景点或统一规则的分布轮廓，原始n单独标注。轴标PC1／PC2和解释方差，文字命名依据载荷产生。
- 增加组间层次聚类热力图／树作为多中心探索。输入为共同尺度下的组均值向量，采用欧氏距离和average linkage；不将可能为负的偏差校正平方距离直接送入聚类。以同一轮bootstrap检查k=2、3时组间同簇频率，保存 `cluster_stability.csv`，不增加重抽样轮次。
- 不预设东亚、欧洲或其他区域必须成簇，也不提前将某组等同于商业／文艺阵营。区域标签仅在结果支持后作为待解释的关联，并检查类型构成的影响；组内差异和聚类不稳定时也须展示。

### 8.3 七组趋近

时期固定为 **2001—2010、2011—2020、2021—2025**。按 5 年分期时 KR 在 2001—2005、2006—2010 均只有 25 部，ZH 在 2001—2005 为 30 部，无法满足 n ≥ 30。按当前分期，七组各期 n 均 ≥ 47。各国家×时期仍按有效特征样本检查 n ≥ 30，低支持格保留状态。

使用第8.1节的国家组等权缩放参数，不按时期重新拟合。每期计算全部21个无序组对的**偏差校正平方距离**，并输出对称7×7矩阵；对角线仅作结构占位，在图中遮蔽：

`D²(a,b) = ||x̄_a − x̄_b||² − tr(S_a)/n_a − tr(S_b)/n_b`

未校正的中心距离会随样本量变小而系统性偏大，因此所有组对统一使用校正公式。区间用组内电影级bootstrap 1000次的百分位区间。

输出 `period_support.csv, pairwise_period_distance.csv, pairwise_period_matrices.npz, convergence_summary.csv`。唯一主汇总指标为 `global_heterogeneity_index = sum(D2(a,b) for all 21 pairs)/21`，正式图注称“七组平均组间异质性（偏差校正平方距离）”，不用它代表所有国家或全部全球电影。

仅在该期七组均满足支持且21对齐全时计算主汇总；否则留空并报告可用对数。可补充对每组都计算 `mean_distance_to_others`，每组都与其余六组等权比较，不为某国单设专属到达曲线。到等权质心的距离是另一项统计量，不能通过改字段名替代两两距离。

汇总区间由同一轮组内电影bootstrap生成：每期每组抽样一次，在该次样本上计算全部21对并等权平均。保存 `convergence_bootstrap.csv`，字段为 `feature_set, period, replicate, pair_or_summary, estimate`。`pair_or_summary`主汇总代码固定为 `global_heterogeneity_index`，不得平均各对区间端点来构造汇总区间，不额外启动第二套bootstrap。

偏差校正后的平方距离估计可能为负，保存原值，不强制截零或开平方。图表轴名与字段注明 `bias_corrected_squared_distance`。

类型构成调整另做补充版本并记录共同支持。解释先报告整体异质性及各对的变化，允许部分组对趋近、另一些分化；不预设多元共生或同质化结论，不将共同变化直接归因为流媒体、数字调色工具或模仿某个国家。
