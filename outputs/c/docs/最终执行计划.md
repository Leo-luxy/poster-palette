## 1. 目标、范围与最终交付

在现有 v2 数据上，以电影为分析单位，完成两个问题：

1. **时间问题：**1950—2025 年全球电影样本的现有海报，整体配色怎样变化？时间分析不区分国家，使用全部配色样本，包括国家信息缺失或归属不确定的电影。
2. **空间问题：**2001—2025 年，不同国家／地区组的海报配色呈现什么特点？组间相差多少？合拍片按参与制片国家与原语言规则推定归属。

产出时间、空间两组图，每组包含“色相分布＋指标”两个图面。报告每组组合成一张图，共两张；PPT 将两个图面分开使用，最多占四页。各组统计直接从对应电影记录计算，每部电影等权。海报墙、单片示例图、额外地图、国家随时间收敛分析和额外聚类均不列入本轮交付，避免增加图片数量。

研究对象统一表述为“按电影上映年份和推定国家／地区组划分的现有海报”。上映年不等于海报设计年；推定归属不等于主制片国、设计地或发行市场。结论描述样本关联，不直接解释为审美变化或国家文化的因果作用。

## 2. 核心执行口径

以下为固定实施口径，具体规则和方法在后续章节展开。

| 事项 | 最终执行决定 |
| --- | --- |
| 国家归属 | 使用原语言辅助分配；合并地区组使用 `region_merged`，保留合并前的合拍属性 |
| 时间范围 | 时间分析：全球样本 1950—2025 年；空间分析：指定七组 2001—2025 年，两套样本分别筛选 |
| 时间平滑 | 五年居中窗口内的逐片记录重新计算中位数，不平滑年度中位数 |
| 组间比较 | 保留各组实际样本构成，直接比较对应指标的均值、中位数及分布 |
| 色相 | 电影等权平均；不把扇区比例之和当独立频数做普通卡方 |
| 直观展示 | 使用完整样本汇总的真实色相占比条，颜色表示色相、长度表示占比；明暗和鲜艳程度由指标图说明 |
| 图表简明性 | 图内只保留读图所需标签和共用图例；方法、完整数值与片单放正文或附表，避免重复注释和多层曲线叠加 |
| 时间解释 | 不预设单调变化，不预设 1970s—1980s 是历史断点 |
| 图片数量 | 报告两张组合图；PPT 最多四页，复用同一组统计与绘图，不额外增加分析图 |

### 4.2 执行顺序

1. 将 `production_countries` 按 `|` 拆分、去除空项并对国家码去重，保留为 `countries_raw`。据此计算 `n_countries_raw`，以原始国家数大于 1 定义 `is_coprod=1`。CN、HK、TW 统一映射为 ZH，RU、SU 统一映射为 RU，其余国家码保持不变；该映射不改变原始国家数。

3. 原始仅一国：归其分析组，`rule=solo`。
4. 原始多国但合并后只有一个组：归该组，`rule=region_merged`，仍保留 `is_coprod=1`。
5. 其余合拍片：先求“原始参与国 ∩ 语言候选国”，再映射并去重为候选组。仅一组时用 `lang_unique`；多组且命中固定优先规则时用 `lang_primary`；否则用 `ambig`。

## 5. 时间分析：配色变化与图 2

### 5.1 原始统计

主指标为 `mean_v`、`mean_s`、`colorful`。这里的 `mean_v`、`mean_s` 是单张海报的像素均值；跨电影汇总时需另标明采用均值或中位数。

- 按年、十年从逐片记录计算 `n_total`、各指标 `n_valid`、均值、中位数、Q1、Q3；另记录 `sat_frac` 中位数及 `sat_frac < 0.10` 的比例。
- 展示平滑线采用 `[y−2, y+2]` 完整五年窗口内所有电影的中位数和 IQR。1950—2025 年样本下仅对 1952—2023 年形成完整窗口，端点不补值。
- 窗口另存 `n_window`；年度原始统计保留在表中，若用于附录绘图，仅对年度 `n_valid >= 30` 的年份绘制，低样本年份不连接跨缺口线段。
- 十年均值、中位数直接由该年代电影计算，电影级 bootstrap 1,000 次给出百分位 95% CI，固定种子 42。
- 2020 年代明确标注为“2020—2025”，不能与完整十年混称。IQR 表示片间分布，CI 表示估计不确定性；各图仅解释实际展示的区间，不重复堆叠两种区间。

### 5.2 年代差异与趋势概括

主时间对比预先设为 **2010—2019 相对 1950—1959**，便于比较两个完整年代；2020—2025 相对 2010—2019 为补充描述。直接比较各年代的指标均值，报告差值与 95% CI。差值区间在两个年代各自的电影样本内独立 bootstrap 1,000 次，每次计算均值差，再取百分位区间。

Spearman ρ 和 Theil–Sen 每十年斜率只概括有效年度中位数序列，使用相同的年度样本门槛，不对平滑曲线做独立样本检验，也不把忽略时间相关性的 p 值作为主要证据。

## 6. 国家分析：配色分布、组间差异与图 4

### 6.1 分组统计

在 2001—2025 年范围内，按七组实际纳入的电影计算三个指标的均值、中位数、IQR、有效 n；均值及中位数的 CI 用电影级 bootstrap 1,000 次计算。指标图展示各组均值及 95% CI，中位数和 IQR 保留在描述表中，体现组内分布。

### 6.2 效应量与结果解释

报告表完整保留六个国家／地区对比 × 三个指标的均值差及区间，不按显著性挑选结果。均值差的 CI 在两组各自样本内独立重采样 1,000 次、每次计算均值差后取百分位。Cliff’s δ 可作为分布差异的补充，不另绘图。

不将“统计显著”直接写成“实际差异很大”。以明度／饱和度的 0—1 尺度、丰富度原单位和样本分布解释量级。CI 默认标明逐项 95% 区间，不声称具有同时覆盖率；若另报 18 个国家指标对比的 p 值，将其作为同一比较族用 Holm 校正。Kruskal–Wallis 等整体检验不列为必交。

## 7. 图表展示与 PPT 分配

### 7.1 色相分布

时间与国家共用以下口径：

1. 仅对 `sat_frac >= 0.10` 的电影计算色相，另记 `n_hue`；这一步不删除明度、饱和度和丰富度分析中的灰海报。
2. 每部电影先检查 12 扇区非负、有限且总和大于 0，再归一到和为 1，组内按电影等权平均。异常向量单独记录，不静默填补。
3. 结果含义为“组内电影的平均色相分布”，不能解释为所有海报像素合并后的占比。
4. 使用 12 扇区的 100% 堆叠色带；各图固定按红至紫再回到红的色相顺序，用扇区中心色相着色。每张图只设一条共用色相图例，标注红、黄、绿、青、蓝、紫等主要色名，完整角度区间保留在表中。色块长度表示占比，展示色不编码该组实际明度或饱和度；这两项由指标图说明，不从色带的鲜艳程度推断样本明暗或饱和度。
5. 不对比例求和表做普通卡方。色相本轮以分布图和结果表描述，不增加额外检验图。

每组的 `n_total`、`n_hue` 和近灰比例完整记录在结果表中；主图只在统一位置显示一次总样本量，图注简要说明色相经过近灰筛选。色相分布的分母为可用色相电影数，近灰比例的分母为该组全部电影数。色相不足 30 部的组不绘制占比估计。

### 7.2 最多四页 PPT 的分配

| 页次 | 使用的图面 | 要讲清楚的内容 | 留给报告的内容 |
| --- | --- | --- | --- |
| 1 | 全球年代色相带 | 1950—2025 年全球电影样本中，颜色构成怎样变化 | 各年代完整比例、近灰比例、样本细节 |
| 2 | 全球明度与饱和度趋势 | 整体是否变亮／变暗、变鲜艳／变灰淡；变化是否单调 | 丰富度小图、完整年代差值与 CI、趋势统计表 |
| 3 | 七组国家／地区色相带 | 2001—2025 年美国、英国、法国、意大利、日本、华语组、韩国有哪些配色差异 | 其他国家描述表、完整色相数值 |
| 4 | 七组明度与饱和度对比 | 组间实际差多少、组内估计有多确定 | 丰富度小图、六个对比的完整差值与 CI 表 |

PPT 每页一幅主要图面，配一句基于实际结果的结论；不另设独立方法页。明度与饱和度是展示页优先指标，丰富度仍完整保留在报告与结果表，不因未进入 PPT 而省略分析。若实际只给三页，将时间和空间的两组指标小图并排放到一页，保留两张直观色相图各占一页，不增加新图。

报告只保留时间、空间两张组合图，复用上述图面，并各自加入丰富度小图。PPT 四幅导出图片是同一组图面的排版版本，不算四项额外分析。其余详细信息尽量使用结果表，不再单独绘制样本量图、效应量图或重复分布图。

海报图片原本用于帮助读者把统计与实际画面联系起来，但少量示例无法代表整个年代或国家组，也会占用展示空间。因此本轮移除海报墙与示例选片流程，直观配色图直接来自完整样本的颜色分布。

### 7.3 图表简明性要求

- 图内保留短标题、必要轴标签和单位、分组名称、每组一次总样本量，以及每种视觉编码的一份共用图例。同一图面内不重复写相同说明。
- 色相色块不逐块标百分比；指标点和曲线不逐点标值、不添加显著性星号。
- 计算参数和完整数值放正文或附表。图注使用短句，只解释样本口径和图中区间；不在绘图区放长段文字。
- 时间主图只保留一条趋势线和一种区间带；国家指标图每国只保留一个均值点及其区间，避免额外叠加统计层。
- 留出足够空白，弱化网格和装饰。报告按实际插入尺寸、PPT 按全屏投影尺寸分别检查可读性；拥挤时先移出次要文字和细节，不靠缩小字号容纳全部信息。
