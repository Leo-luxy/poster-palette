# PPT 图面与建议讲述

建议按时间、国家两个部分各安排三页；典型配色页使用单片示例，整体结论仍以色相及指标页为准。

1. `fig_q2_palettes.png`：各年代的一张选定海报被概括成色块，帮助直观感受配色；不能把单片示例当作年代平均。
2. `fig_q2_hue.png`：1950 年代到 2010 年代，0°—60° 色相合计的电影平均占比由 58.6% 降至 47.8%，180°—240° 合计由 17.4% 升至 27.7%。色带仅包含可用色相的电影，显示色不代表实际明暗或饱和度。
3. `fig_q2_metrics.png`：2010 年代相对 1950 年代的平均明度低 0.0705、平均饱和度低 0.0187；五年窗口趋势并非单调。阴影为片间四分位距，不是置信区间。
4. `fig_q4_palettes.png`：七组各选一张海报概括为色块，用于直观展示配色；不能代表整组或解释国家文化。
5. `fig_q4_hue.png`：七组的平均色相构成各不相同，例如日本组 0°—60° 合计约 37.5%，美国组约 48.4%；这是样本描述，不是国家文化的因果解释。
6. `fig_q4_metrics.png`：韩国组较美国组平均明度低 0.0772、饱和度低 0.1032；图中各点为组均值，横线为逐项 95% 置信区间。差值的区间见国家结论表。

时间按电影上映年分组，海报设计年未知；国家／地区按参与国和原语言推定。样本受 TMDB 覆盖和每年票数前 2.6% 的筛选影响，较新电影积累投票时间较短，2020—2025 不构成完整十年。
