# 增量分析结果与解释边界

本次使用 1950—2025 年 19,694 部配色匹配电影，国家比较使用 2001—2025 年七组 10,115 部电影。组归属沿用既有表；时间样本保留国家缺失电影。每年按票数前 2.6% 选样，覆盖与投票积累差异限制外推。电影上映年并非海报设计年，推定国家组也不等于设计地或主制片国。

## 时间对比

2010—2019 相对 1950—1959，明度均值差为 −0.0705（逐项 95% bootstrap CI −0.0840 至 −0.0588）；饱和度均值差为 −0.0187（−0.0326 至 −0.0063）。在相应有效子集中，前两有色像素聚类的 ΔE76 均值差为 −14.72（−16.36 至 −13.14），30° 色相投影均值差为 −0.222（−0.257 至 −0.185）。这些对比使用电影级组内重抽样，不表示全部电影的历史因果变化。主辅色只来自有色像素聚类，不表示全画面面积最大的两个颜色；色相投影为轴向统计量，不是心理冷暖量表。

## 七组异质性

基础特征集的七组 21 对偏差校正平方距离均值，三期分别为 1.111、0.988、0.354；逐项 95% 区间分别为 [0.913, 1.581]、[0.811, 1.369]、[0.332, 0.751]。这是七组样本在固定国家组等权坐标系下的描述，不是所有国家的全球趋势，也不能据此判定传播机制。各对结果保留在长表中，可能呈现不同方向。扩展特征集各期只有 10、15、10 对满足支持条件，主汇总按规则留空。

类型调整补充版把多标签电影同时计入其类型，以各期七组均至少有 5 部完整案例的共有类型构造等类型均值；相同共有类型用于三个时期。基础集共有类型为 18、35、53、80，三期点估计分别为 0.565、0.556、0.350。第三期有 993/1000 个联合重抽样有效，因此区间留空；扩展集因国家×时期完整案例不足未计算总体估计。此敏感性分析对类别重叠和共同支持范围敏感，不替代主分析。
