# 图件与原图目视检查

已查看全部报告图的缩略总览，并放大核对时间共现图、国家空间图、冷暖双联图、扩展集趋近图及 20 张原图核查总览。检查了图例、颜色尺度、图框和标签是否可辨，国家空间图的 V/S 绝对图及两种残差均有对应色标；扩展集不满足完整支持的时期明确留空。原图中四类极值各两张与对应亮度、色差方向一致；另外 12 张随机样本的视觉特征与指标量级相容，逐张记录见 spot_check_audit.csv。目视核查用于发现明显不一致，数值正确性另由脚本和自动验收检查。

冷暖椭圆展示组均值的不确定性；聚类和趋近图均不预设国家参照。报告图中未发现被截断的主要图面；PPT 文件单独以 16:9 输出。
