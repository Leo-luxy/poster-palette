# C：海报配色的时间与国家／地区分析

本目录收纳代码、计划、统计表、解读和 PPT 图面。报告图位于仓库的 `figures/c/`：`fig_q2_trend.png`、`fig_q4_country.png` 是统计组合图；`fig_q2_palettes.png`、`fig_q4_palettes.png` 是年代及国家／地区的典型海报抽象配色图；`fig_q2_comparisons.png`、`fig_q4_comparisons.png` 展示预定均值差和区间。

```text
outputs/c/
├── README.md            目录入口
├── run_manifest.json    输入指纹、运行环境和配置
├── palette_manifest.json 配色图的选片与抽象化参数
├── scripts/             国家归属、时间与国家分析、绘图和验收代码
├── docs/                原始执行计划、简明说明及协作推送记录
├── reports/             时间与国家结论、复现说明及验收报告
├── tables/              统计结果、归属记录和输入审计表
└── ppt/                 四张 16:9 图面和逐页讲述建议
```

建议从 [时间结论](reports/时间结论.md)、[国家结论](reports/国家结论.md) 和 [PPT 讲述建议](ppt/讲述建议.md) 查看成果；完整数据表在 `tables/`。可复现步骤见 [复现说明](reports/复现说明.md)，检查结果见 [验收报告](reports/validation_report.md)。

想了解数据处理、时间与国家分析方法以及图表的读法，可以先读 [项目实现与结果解读](项目实现与结果解读.md)。

下一轮扩展分析见 [工程实施规格](docs/现有数据分析升级方案.md)，包含模块依赖、字段与文件契约、默认参数、运行接口、缓存和验收要求；国家分析采用七组等权参照与全部21对比较，第10节明确了趋近、冷暖、空间残差、配色构成、核查卡和森林图六项可视化任务。

`docs/最终执行计划.md` 保留原基线计划，其文件路径属于整理前的历史约定；当前基线目录与命令以本文件及复现说明为准，升级分析按工程实施规格执行。
