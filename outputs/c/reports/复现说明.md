# 复现说明

从仓库根目录运行，需 Python、pandas、numpy、scipy、matplotlib、Pillow；脚本不安装依赖。输入只读，指纹变化会中止，需先核实版本并人工处理旧运行记录。

```bash
python outputs/c/scripts/c01_country_group.py
python outputs/c/scripts/c02_time.py
python outputs/c/scripts/c99_validate.py --stage time
python outputs/c/scripts/c03_country.py
python outputs/c/scripts/c04_palettes.py
python outputs/c/scripts/c99_validate.py --stage all
```

时间图及 PPT 图面由 c02 基于 `time_yearly.csv` 和 `hue_summary.csv` 的 time 行绘制；国家图及 PPT 图面由 c03 基于 `country_summary.csv` 和 `hue_summary.csv` 的 country 行绘制。绘图公共实现为 `outputs/c/scripts/c_plot.py`。时间取 1950—2025 全体匹配记录，国家取 2001—2025 七组；色相仅取 sat_frac ≥ 0.10 且色相有效的记录。筛选与 Bootstrap 参数见 `outputs/c/scripts/c_common.py` 和 `outputs/c/run_manifest.json`。统计表写入 `outputs/c/tables/`，报告图写入 `figures/`，展示图写入 `outputs/c/ppt/`。时间和国家脚本按维度更新共用表。

`data/yearly.csv` 的丰富度中位数只保存两位小数，因此核对容差为 0.005；明度与饱和度使用 0.0001。自动验收只覆盖报告中列出的检查，视觉质量和与 D 的模板对齐仍需人工确认。

`outputs/c/tables/hue_sectors.csv` 记录 12 个 30° 扇区的角度边界；`outputs/c/tables/assignment_summary_2001_2025.csv` 保留空间分析时段的规则覆盖。PPT 配套一句话结论见 `outputs/c/ppt/讲述建议.md`。

## 报告中的典型配色图

`c04_palettes.py` 生成 `figures/fig_q2_palettes.png`、`figures/fig_q4_palettes.png` 和 `outputs/c/tables/palette_summary.csv`。每片使用上游提取的三个主色及其占比，先把每片三个占比归一化，再按电影等权、各自的主色占比加权。按 HSV 将明度小于 0.20 的主色归为暗色，其余饱和度小于 0.20 的归为低饱和色，其余划入 12 个色相区间。每类选取该组现有主色记录中最接近该类加权 RGB 中心的一种颜色，保留该类的加权份额；并非对色彩做饱和度增强，也不是所有海报像素的完整直方图。

上游主色来自去掉海报底部 12% 后、像素饱和度至少 0.20 的区域，不是整个画面的像素构成；缺少有效三色数据的电影不参与配色汇总，每组的有效及排除数量见结果表。每个非空类别按其权重切分为抽象矩形，矩形面积与权重成比例，拼接布局仅用于展示，并非海报的空间布局。每组独立选取代表色，不同类别位置可能随权重变化。汇总色及权重记录在结果表中，分类规则见 `outputs/c/palette_manifest.json`。
