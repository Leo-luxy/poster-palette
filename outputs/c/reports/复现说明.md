# 复现说明

从仓库根目录运行，需 Python、pandas、numpy、scipy、matplotlib、Pillow；脚本不安装依赖。输入只读，指纹变化会中止，需先核实版本并人工处理旧运行记录。

```bash
python outputs/c/scripts/c01_country_group.py
python outputs/c/scripts/c02_time.py
python outputs/c/scripts/c99_validate.py --stage time
python outputs/c/scripts/c03_country.py
python outputs/c/scripts/c04_palettes.py
python outputs/c/scripts/c05_comparisons.py
python outputs/c/scripts/c99_validate.py --stage all
```

时间图及 PPT 图面由 c02 基于 `time_yearly.csv` 和 `hue_summary.csv` 的 time 行绘制；国家图及 PPT 图面由 c03 基于 `country_summary.csv` 和 `hue_summary.csv` 的 country 行绘制。绘图公共实现为 `outputs/c/scripts/c_plot.py`。时间取 1950—2025 全体匹配记录，国家取 2001—2025 七组；色相仅取 sat_frac ≥ 0.10 且色相有效的记录。筛选与 Bootstrap 参数见 `outputs/c/scripts/c_common.py` 和 `outputs/c/run_manifest.json`。统计表写入 `outputs/c/tables/`，报告图写入 `figures/c/`，展示图写入 `outputs/c/ppt/`。时间和国家脚本按维度更新共用表。

`data/yearly.csv` 的丰富度中位数只保存两位小数，因此核对容差为 0.005；明度与饱和度使用 0.0001。自动验收只覆盖报告中列出的检查，视觉质量和与 D 的模板对齐仍需人工确认。

`outputs/c/tables/hue_sectors.csv` 记录 12 个 30° 扇区的角度边界；`outputs/c/tables/assignment_summary_2001_2025.csv` 保留空间分析时段的规则覆盖。PPT 配套一句话结论见 `outputs/c/ppt/讲述建议.md`。

## 报告中的典型配色图

`c04_palettes.py` 生成 `figures/c/fig_q2_palettes.png`、`figures/c/fig_q4_palettes.png`、对应的 16:9 PPT 图面和 `outputs/c/tables/palette_examples.csv`。每组只选择一张海报：先筛选三个指标和色相有效、`sat_frac ≥ 0.10` 的电影；用三个指标相对组内中位数的四分位距标准化距离平方的均值，加上单片色相分布与该组平均色相分布的总变差距离的平方，选择得分最低且本地海报存在的电影，分数相同时取较小 ID。图上不标电影名；选片记录、得分和原始海报 SHA-256 保存在表中以便复核。

抽象化时裁去所选海报底部 12%，缩放并平滑画面后以中位切分法提炼七种颜色，再以 8 × 10 的网格概括色区，将小于三个网格的孤立区域合并到邻近色块，形成方形边界并保留主要颜色在原海报中的大致位置。平滑与简化会改变边界、颜色和面积，图面不作为精确的颜色占比统计。每幅图是单张海报的概括，不是整个组的平均配色或统计分布；色相分布和指标结论应以统计图、表为准。选片与抽象化参数和输入图片指纹见 `outputs/c/palette_manifest.json`。

`c05_comparisons.py` 使用 `tables/contrasts.csv` 生成 `figures/c/fig_q2_comparisons.png` 和 `figures/c/fig_q4_comparisons.png`，分别展示两个预定年代对比和六个国家／地区相对美国的对比；点是均值差，区间是逐项 95% CI。
