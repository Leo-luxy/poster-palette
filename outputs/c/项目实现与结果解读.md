# 电影海报配色分析：实现方法与结果解读

这份文档介绍 C 部分的主要思路：我们怎样把海报变成可比较的数据，怎样观察全球样本随时间的变化，以及怎样比较不同国家／地区组。重点是帮助理解结果；具体公式、完整结果和运行命令可以再查[复现说明](reports/复现说明.md)和 `tables/`。

## 一、项目要回答什么

我们研究的是**现有电影海报的配色**，分别回答两个问题：

1. 按电影上映年份看，1950—2025 年全球样本的海报配色怎样变化？
2. 按推定的国家／地区组看，2001—2025 年的海报配色有什么差异？

两项分析都以**电影为单位**：每部电影在所属统计组中占一票，而不是让像素多的海报获得更大权重。数据来自已有的电影信息、制片国家信息和海报配色特征；本项目不重新采集数据，也不修改公共数据。

需要先区分两类图：**统计图**汇总对应范围内的电影，用来回答“整体怎样”；**典型配色图**每组只从一张选定海报生成，用来直观感受某种配色，不能代替整组统计。

## 二、怎样把海报变成可比较的数据

### 1. 连接电影和颜色

代码用电影 ID 将影片信息、海报特征和制片国家信息对应起来，并检查 ID 是否重复、连接后是否仍然一片一行。当前有 **19,694 部**电影能匹配到配色特征，作为时间分析的基础样本。其中 20 部缺少制片国家信息，仍保留在时间分析中。

现有数据原先从海报提取了颜色特征：计算前裁去海报底部约 12%，以减少演职员表等区域的干扰。因此，下文的“海报颜色”具体指这个既定处理口径下得到的颜色特征，不是对原图每个像素重新统计。

### 2. 用什么描述颜色

分析主要使用三项指标，并结合色相分布：

| 内容 | 通俗理解 | 怎么看数值 |
| --- | --- | --- |
| **明度** | 海报整体偏亮还是偏暗 | 0—1，越大越亮 |
| **饱和度** | 颜色偏鲜艳还是偏灰淡 | 0—1，越大越鲜艳 |
| **色彩丰富度** | 画面颜色变化和色彩对比的综合程度 | 数值越大，通常表示色彩更丰富；它不是颜色种类数 |
| **色相分布** | 红、黄、绿、蓝等颜色所占的相对份额 | 先计算每张海报的颜色分布，再对电影等权平均 |

明度、饱和度和丰富度先在单张海报上计算，再按年份或国家／地区汇总。比如“某组明度均值为 0.52”，意思是该组各电影海报明度的平均值为 0.52。

色相图另有一道筛选：如果一张海报中有足够饱和度的像素占比不足 10%，它的色相难以稳定概括，就不纳入色相分布；这类海报仍保留在明度、饱和度和丰富度分析中。因此，色相图使用的有效海报数可能小于图上标注的组总数。

## 三、时间分析：全球配色怎样变化

### 1. 方法

时间分析使用 **1950—2025 年全部 19,694 部匹配电影**，不按国家筛选。代码将每部电影按上映年归入年代，再从逐片数据计算年代色相分布和指标统计。

趋势图还使用**五年居中窗口**：例如画 2000 年时，把 1998—2002 年的电影放在一起，计算这些电影指标的中位数。窗口每年移动一次，使曲线较容易看出变化，同时保留非单调的起伏。只有窗口完整的年份才画线，所以曲线从 1952 年到 2023 年；它不是把年度中位数再做平均。

为了给变化一个可比较的数值，分析预先比较 **2010—2019 年与 1950—1959 年**的指标均值，并用重复抽样估计差值的不确定性。2020—2025 年与 2010—2019 年的比较作为补充，因为前者只有六年，不是完整十年。

### 2. 结果与理解

从当前样本看，2010 年代相对 1950 年代：

| 指标 | 1950 年代均值 | 2010 年代均值 | 后者减前者 |
| --- | ---: | ---: | ---: |
| 明度 | 0.600 | 0.530 | **−0.070** |
| 饱和度 | 0.412 | 0.394 | **−0.019** |
| 色彩丰富度 | 73.89 | 57.00 | **−16.88** |

这些结果说明，两个完整年代相比，2010 年代样本的海报平均更暗、饱和度略低，丰富度也较低。但变化**不是每年都沿同一方向**：例如 2020—2025 年相对 2010 年代，明度均值继续下降，而饱和度均值上升。不能把整条历史概括成“持续变灰”。

具体读图时，可以结合：

- [全球时间统计图](../../figures/c/fig_q2_trend.png)：上半部分是各年代平均色相分布；下半部分三条线分别是明度、饱和度、丰富度的五年窗口中位数。线周围的浅色带表示同一窗口中间 50% 电影的分布范围，说明影片之间差异有多大，**不是置信区间**。
- [全球年代典型配色图](../../figures/c/fig_q2_palettes.png)：每个年代选一张海报，把其主要颜色区域方块化，用于直观展示该海报的配色和大致布局。它不是该年代海报的平均图，也不能仅凭它判断整个年代的配色趋势。
- [全球年代差值图](../../figures/c/fig_q2_comparisons.png)：直接对比两个预定年代组合的指标均值差及其逐项 95% 置信区间。

色相条中的颜色表示**色相类别**，长度表示平均占比；色条本身使用统一展示色，不表示那个年代的实际明度或饱和度。明暗和鲜艳程度应看下面的指标图。

## 四、国家分析：不同组有什么差异

### 1. 先给电影分组

一部电影可能有多个参与制片国家，不能简单把它重复放入多个组。因此，项目结合**参与制片国家和电影原语言**，为每部电影推定一个组：单一制片国家的电影直接归组；合拍片则按原语言与参与国的匹配关系处理。如果仍不能明确归属，就标为“归属不确定”，不进入国家比较。中国大陆、香港、台湾在分析中合为**华语组**。

这种分组便于比较，但只是规则推定：它不等于已经证实影片的主制片国，更不等于海报的设计地。合拍片在归组时仍保留其原始参与国家信息，方便追查。

### 2. 方法和样本

国家分析只使用 **2001—2025 年**，固定比较七组：美国、英国、法国、意大利、日本、华语组、韩国。这个时期共有 11,918 部匹配电影；其中七组纳入 **10,115 部**，其余为其他国家／地区、归属不确定或缺少国家信息。

代码分别计算七组的色相分布和三项指标，保留各组实际电影构成；它没有把各组调整成相同的类型或年份结构。为了便于阅读，还预先用美国组作为共同参照，计算其余六组分别与美国组的均值差。

### 3. 结果与理解

明度和饱和度可以先看几个具体例子：

| 组别 | 电影数 | 明度均值 | 饱和度均值 |
| --- | ---: | ---: | ---: |
| 美国 | 7,349 | 0.519 | 0.416 |
| 法国 | 976 | 0.579 | 0.405 |
| 意大利 | 448 | 0.591 | 0.392 |
| 华语组 | 195 | 0.468 | 0.406 |
| 韩国 | 216 | 0.442 | 0.312 |

例如，法国组的平均明度比美国组高约 **0.060**；韩国组比美国组低约 **0.077**。韩国组的平均饱和度比美国组低约 **0.103**。这些差值描述的是所纳入电影的平均差异，并不表示该组每一张海报都如此，也不能直接归因为国家文化。

具体读图时，可以结合：

- [国家／地区统计图](../../figures/c/fig_q4_country.png)：上半部分比较七组色相分布；下半部分每个点是该组指标均值，横线是该均值的逐项 95% 置信区间，用来表示估计的不确定性。
- [国家／地区典型配色图](../../figures/c/fig_q4_palettes.png)：每组从配色指标接近组内中心的电影中选一张海报，再简化成方形色块。它便于感受具体配色，但不能代表整个国家或地区的所有海报。
- [国家／地区差值图](../../figures/c/fig_q4_comparisons.png)：直接显示六组分别减美国组的指标均值差及其逐项 95% 置信区间。

图中各组点旁的横线是**各组均值**的区间，不是“两组均值差”的区间。若要判断法国组与美国组相差多少及差值的不确定性，应看[国家结论](reports/国家结论.md)或 `tables/contrasts.csv` 中直接计算的对比。

## 五、怎样理解“不确定性”

项目采用一种直观的重复抽样方法：在已有电影中，按组有放回地反复抽取样本，每次重新计算均值或均值差，共重复 1,000 次，再从这些结果中取出 95% 的百分位区间。这个区间反映了在当前样本及方法下，估计值对电影样本变化的敏感程度。

例如，法国组减美国组的明度均值差为 **+0.060**，对应逐项 95% 区间约为 **+0.048 至 +0.071**。可以把它理解为：按照本次抽样方法，法国组平均明度高于美国组的估计幅度大致落在这个范围；它不表示每张法国组海报都比美国组海报亮，也不说明造成差异的原因。

不同对比分别给出逐项区间，不表示所有区间同时具有 95% 的覆盖保证。时间趋势图的浅色带是影片间分布，国家指标图的横线是均值的不确定性，两者含义不同。

## 六、结论能说到哪里

这份分析反映的是**现有样本中的关联和差异**，解释时有三个关键边界：

1. **上映年份不等于海报设计年份。** 我们按电影上映年分组，不知道每张现有海报具体何时设计。
2. **推定国家组不等于海报设计地。** 合拍片归属依赖参与制片国家和原语言规则，不能据此认定设计者来自哪个国家，也不能直接解释为文化造成的结果。
3. **样本不等于全部电影。** 数据受 TMDB 覆盖和每年按票数前 2.6% 筛选的影响；不同年份电影积累投票的时间不同，2020—2025 年又不是完整十年。

因此，较稳妥的表述是：“在这批按上述规则选出的电影海报中，观察到这些配色变化和组间差异。”
