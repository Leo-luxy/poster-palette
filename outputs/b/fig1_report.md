## 一、 可视化设计创新与物理可解释性（供大作业正文与 PPT 汇报）

针对传统统计柱状图“抽象单调、看不出什么色聚集到什么色”的痛点，图 1 采用**物理色彩流形渲染（Photorealistic Palette Flow）**，由三大互补面板构成：

1. **面板 A【极坐标 2D 核密度星云与 4 大物理色型质心锚点】**：
   - 基于全量 19,072 部海报在极坐标下的连续分布，计算平滑高斯核密度等高线（Polar 2D KDE Contours，通过笛卡尔坐标变换根除 0°/360° 周期边界失真）；
   - 提取 2,200 张真实海报的 Hex 主色（`dom1`），投射在 HSV 极坐标色盘上（极角 $\theta = \text{色相}$，极径 $r = \text{饱和度}$）；
   - 显式落盘 4 大客观色型的真实物理质心锚点（$\bigstar$）：225° 聚集为冷光青蓝区、外圈高饱和处聚集为高饱和艳丽区、内圈低明度聚集为极致暗黑区（质心 $V=0.28$）、东侧高明度聚集为高亮通透区（质心 $V=0.74$）。
2. **面板 B【8 大主流类型真实海报色彩基因光谱带 (Genome Ribbons)】**：
   - **100% 数据驱动物理呈现**：针对每个类型在 12 色相扇区内的所有真实海报样本，提取其实测平均饱和度与明度，严格转换为真实 RGB 颜色渲染，彻底杜绝主观臆断；
   - 动画如彩虹绚烂（丰富度 81.0），喜剧暖调明亮（60.9%），爱情高明暖红（63.1%），剧情写实均衡，动作冷夜金属（32.0%），科幻青蓝冷光独占（39.0%），犯罪冷夜深暗（$V=0.48$），恐怖全带压抑暗化（中位明度仅 0.38）。
3. **面板 C【8 大类型在 4 大物理色型中的流向热力矩阵与超配比率】**：
   - 每行严格归一化为 100%，各类型的行峰值优势色型以**金色高亮描边与星标（★）**突出显示；
   - 引入经济学标准的**超额配置比率（Over-representation Ratio / $\text{Ratio} = \text{类型占比} / \text{全库基准}$）**，并在底部追加【全库大盘基准（Baseline）】行；
   - 卡方独立性检验（$\chi^2 = 2482.5, p < 10^{-300}, \text{Cramér's } V = 0.162$）证实题材对配色的显著偏向。

## 二、 多策略聚类评测与最优方案选型论证（Benchmark Comparison）

为了响应“多尝试几种聚类策略并选出最优方案”的要求，我们构建了 **4 种聚类算法 $\times$ 3 种特征表征空间 $\times$ 4 个簇数 $k$（共计 48 组策略组合）** 的全量基准测试实验（详见 `outputs/b/clustering_benchmark.py` 与 `outputs/b/clustering_benchmark.csv`）。

### 1. 策略维度设计
- **聚类算法范式（4 类）**：
  1. **K-Means（质心划分）**：基于欧氏距离优化球形簇，质心物理意义清晰；
  2. **Bisecting K-Means（二分 K-Means）**：自顶向下二分迭代，抗局部最优；
  3. **Gaussian Mixture Model (GMM, 高斯混合模型)**：基于 EM 算法的概率软划分与协方差椭球拟合；
  4. **Agglomerative Hierarchical Clustering (Ward linkage, 层次凝聚)**：自底向上最小化方差平方和，生成刚性谱系树。
- **特征表征空间（3 类）**：
  1. **`Base_5D`（宏观色彩空间）**：`[mean_v, mean_s, colorful, sin_hue, cos_hue]`（队长推荐的基础特征集，含周期性色相三角映射）；
  2. **`Contrast_6D`（对比度增强空间）**：`[mean_v, v_std, mean_s, colorful, sin_hue, cos_hue]`（加入明暗标准差 `v_std`，衡量动态范围）；
  3. **`Spectral_15D`（全光谱直方图空间）**：`[mean_v, mean_s, colorful, h0..h11]`（利用 12 扇区色相比例直接表征颜色分布）。
- **聚类簇数**：$k \in \{3, 4, 5, 6\}$。

### 3. 最优方案选型依据（Pareto 决策）

根据 48 组实验的综合帕累托前沿权衡，**`Base_5D` 特征空间 + `K-Means (k=4)` 成为确定性最优解**，核心证明如下：
1. **簇间分离度达到全局峰值**：Davies-Bouldin 指标（DB = 1.211）为全场 48 组配置中**最低（最优）**，Calinski-Harabasz 指标高达 6946.6；
2. **分布最均衡、无退化簇**：各簇样本数量分别为 5,455（28.6%）、4,673（24.5%）、4,272（22.4%）、4,672（24.4%），最小簇占比高达 22.4%，彻底杜绝了边缘孤立噪点簇（Bad cases）；
3. **帕累托前沿拐点（Knee Point）**：在几何紧致度（Silhouette）与题材外部解释度（Cramér's V）的双目标优化中，该组合处于凸包拐点，实现了边际效益最大化；
4. **物理可解释性极佳**：4 个质心能严格对应到物理色彩空间的四个象限（青蓝冷光、压抑极暗、高纯艳丽、通透高亮），便于大作业报告与答辩展开论述。

## 四、 做法 A（预设对比）深度分析与分布全貌

在 `figures/fig_q1_preset_bars.png` 中，我们以科幻、爱情、恐怖三大典型题材为对象展开做法 A 对比：
1. **物理光谱色带对齐（面板 A）**：
   - 柱状图底部显式绘制 12 扇区真实光谱色条（从 0° 红至 330° 红紫）；
   - 爱情在 0–30° 暖红峰值达 38.3%（高调浪漫）；科幻在 210–240° 青蓝达 14.6%（深空科技）；恐怖在 120–150° 偏冷绿达 2.7%（阴森鬼火）；
   - 12 扇区卡方检验 $\chi^2 = 175.9, p = 5.4 \times 10^{-26}, \text{Cramér's } V = 0.104$。
2. **全量概率分布与非参数检验（面板 B）**：
   - 采用半小提琴核密度（KDE Cloud）叠加四分位箱线（IQR 25%~75%）与均值菱形标，解决大样本下 SE 缩为一点的视觉掩盖问题；

     - 明度：$H = 1550.1, p < 10^{-250}$，爱情（均值 0.60）比恐怖（均值 0.40）高出 0.20，效应量高达 $\eta^2 = 0.192$（大效应量）；
     - 丰富度：$H = 121.9, p < 10^{-25}$，爱情（均值 64.6）比恐怖（均值 57.1）高出 7.5；
     - 饱和度：$H = 193.0, p < 10^{-40}$，饱和度差异微弱。

## 五、 稳健性检验与敏感性分析（交接文档潜在干扰因素逐一击破）

针对《交接文档》提出的“人脸肤色干扰”、“近灰海报过滤阈值”及“历史时期干扰”，我们执行了全量敏感性测试（脚本：`outputs/b/sensitivity_analysis.py`，结果：`outputs/b/sensitivity_analysis.csv`）：

### 1. 人脸/肤色波段（10–40°）敏感性剔除实验
- **背景假设**：爱情片偏红是否因男女主角大头贴特写肤色导致？科幻片偏蓝是否因无人脸导致？
- **检验设计**：剔除所有海报主色落在 10–40°（肤色黄金区间）的样本（共计 6,039 部，占 31.7%），在剩余的 13,033 部纯净背景海报上重新检验：
  - **12 扇区卡方检验**：在完全剔除肤色后，$\chi^2 = 85.3, p = 2.12 \times 10^{-9}$，仍然极度显著；
  - **爱情片暖红率**：从 38.3% 下降至 28.1%，但**依然稳居爱情片所有 12 个扇区的最高峰**！
  - **科幻片青蓝率**：从 14.6% **逆势上升至 17.9%**（效应量净增 +3.3%），冷光特征更为纯粹；
  - **明度 Kruskal-Wallis 检验**：明度差异检验 $H$ 值依然破千（$H = 1040.7, p < 10^{-220}, \eta^2 = 0.181$ 大效应量）；
- **结论**：**证伪“人脸假象假说”**！海报配色的题材偏向是电影工业自觉的类型美学选择，绝非演员人脸特写的附带统计噪音。

### 2. 近灰海报过滤门槛敏感性扫描 (`sat_frac` 扫描 0.05 ~ 0.15)
- 扫描 `sat_frac` 在 0.05（宽容，N=19,356）至 0.15（严苛，N=18,781）的五档阈值：
  - 卡方独立性统计量在 171.5 ~ 176.3 之间微幅浮动；
  - 效应量 Cramér's V 极其恒定地落在 **0.1038 ~ 0.1044** 之间（极差 $< 0.0006$）；
- **结论**：过滤门槛变动不影响核心聚类与分类对比结论，系统具备绝对数值刚性。

### 3. 跨时代（1950s–2020s）4 大色型稳定性与流变脉络
追踪 1950s 至 2020s 八个年代在 4 大客观色型上的分布演进，揭示好莱坞工业色彩的历史变迁：
- **冷光青蓝调**：1950s（15.6%）与 1960s（15.2%）处于低位，自 1980s 商业大片时代（31.1%）爆发，2020s 跃升至 **34.0%**；
- **极致暗黑调**：从 1950s 的 17.3% 一路上扬至 2020s 的 **29.2%**；
- **高亮通透调**：从 1960s 的 **40.0%** 持续萎缩至 2020s 的 **16.9%**；
- **高饱和艳丽调**：1950s 胶片时代高达 36.2%，之后平稳维系在 20%~25% 区间。
- **与 C 联动**：该演化完全印证了组长在 README 中指出的“整体在变暗、变收（明度 0.61 $\to$ 0.50）”的宏观规律，并为 C 的图 2 年代趋势提供了结构层面的坚实佐证。

### 2. 答辩防守 Q&A 话术（为 D 答辩准备的防御性弹药）
- **Q1：爱情片偏红、恐怖片偏暗，是不是演员大头特写人脸肤色或黑白老片造成的统计假象？**
  - **答辩标准回答**：我们专门设计了人脸肤色剔除敏感性实验（剔除 10–40° 肤色区间，共排除 31.7% 的样本）。结果显示：剔除人脸肤色后，爱情片在 0–30° 暖红率依然达 28.1%，依然是其所有扇区的绝对最高峰；科幻片青蓝率反而逆势升至 17.9%；三类明度的 Kruskal-Wallis 检验 H 值依然破千（$H=1040.7, p < 10^{-220}, \eta^2=0.181$ 大效应量）。这充分证明该现象是电影工业的自觉美学选择，而非人脸特写的副产物。
- **Q2：聚类簇数 k 为什么选 4，而不是 3 或者 5？**
  - **答辩标准回答**：在 48 组策略横向评测中，$k=4$ 取得了全场最低（最优）的 Davies-Bouldin 指标（1.211）；同时在轮廓系数与题材区分度（Cramér's V）的双目标优化中，它处于帕累托前沿的曲率拐点（Knee Point）。当 $k=3$ 时，题材区分度暴跌 24%（$V$ 从 0.161 跌至 0.122）；当 $k=5$ 时，最小簇跌至 13.7%，衍生出边缘碎片簇且解释性下降。因此 $k=4$ 在数学几何指标与电影学解释力上均具备全局最优性。
- **Q3：这 4 个色型在历史年代中稳定吗？好莱坞大片是否有影响？**
  - **答辩标准回答**：我们对 1950s 至 2020s 展开了跨时代演变审计。数据证实：4 大色型贯穿了整部现代电影史，但在配比上呈现清晰的工业演变脉络——1980s 商业大片兴起后，冷光青蓝占比从 15% 激增至 34%，极致暗黑从 17% 升至 29%，而通透高光从 40% 压缩至 17%。这与现代电影 CGI 视效普及以及好莱坞“青橙冷暖对比”套路的流行完全吻合。
