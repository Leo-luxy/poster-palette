## 一、 核心结论（PPT 一句话速记）

**海报配色存在强烈的“类型套路”：明度（亮度）是区分电影类型的第一分水岭（爱情比恐怖高出 0.28，效应量 $\eta^2 = 0.216$）；而在色相上，科幻呈现显著的“冷青蓝偏好”（冷色率达 55.0%），爱情呈现“高明暖调”，恐怖片则呈现“极端暗化与灰绿压抑”。这一色系差异在剔除人像肤色干扰后依然稳健。**

## 二、 详细学术解读（供报告正文第 5 节“图 1 分析”引用）

### 1. 连续色彩特征：明度构成跨类型的绝对鸿沟
在三类代表性电影中，明度（`mean_v`）呈现极其陡峭的阶梯级差异（Kruskal-Wallis $H = 1349.64, p < 10^{-290}, \eta^2 = 0.216$，属于典型的大效应量）：
- **恐怖片（极暗化）**：明度中位数仅为 **0.35**（IQR = 0.25），超过 75% 的恐怖片海报明度低于 0.50，视觉上通过大面积暗部、低光影与黑底构建压抑、未知的惊悚氛围；
- **科幻片（中暗冷调）**：明度中位数为 **0.47**（IQR = 0.24），通常依托深邃的太空暗色或冷光高对比度；
- **爱情片（高亮暖光）**：明度中位数高达 **0.63**（IQR = 0.27），比恐怖片整整高出 **0.28**（Mann-Whitney $U = 4.11 \times 10^6, p < 10^{-265}$），通透轻快，契合浪漫温暖的情感期待。
- *色彩丰富度与饱和度*：虽然饱和度（$H = 116.59$）与色彩丰富度（$H = 202.52$）在统计学上也显著，但效应量（$\eta^2 = 0.018 \sim 0.032$）远低于明度，说明**亮度反差是大众对类型海报的第一视觉感知抓手**。

### 2. 色相分布（Hue）：科幻偏蓝、爱情偏暖、恐怖偏绿
12 扇区卡方独立性检验表明，色相分布与电影类型高度相关（$\chi^2 = 169.11, df = 22, p = 1.11 \times 10^{-24}, \text{Cramér's } V = 0.118$）：
- **科幻片**：在 180°–240°（青色与蓝色扇区）形成极为显著的“冷色尖峰”，青蓝波段像素占比达 **34.3%**（远高于爱情片的 21.5%），展现出强烈的机械科技、外星与未来感；
- **爱情片**：在 0°–30°（红橙色）占比高达 **38.4%**，在 30°–60°（暖橙色）达到 15.9%，红暖色系主导视觉基底；
- **恐怖片**：除暗黑色调外，在绿光波段（90°–150°，如腐烂、幽灵、暗夜绿等）占比（10.2%）高于爱情片（7.2%）。

### 3. 稳健性与敏感性消融：人脸肤色的干扰排除
- **问题提出**：电影海报大量包含演员面部特写，而人类肤色在 HSV 色相空间天然聚拢在 10°–40°（暖红橙）。爱情片红橙高占比是否仅因“双人特写多”？科幻偏蓝是否仅因“人物出镜少”？
- **消融检验**：剔除 0°–30°（h0 扇区）肤色基底后重新归一化计算，卡方检验依旧极度显著（$\chi^2 = 94.00, df = 20, p = 1.47 \times 10^{-11}, \text{Cramér's } V = 0.107$）；
- **结论证实**：剔除肖像基底后，科幻片的冷色调（青/蓝）占比从全量的 40.9% 进一步跃升至 **55.0%**（提升了 14.1 个百分点），稳居三类之首；爱情片与恐怖片冷色率分别为 42.2% 与 45.7%。这雄辩地证实：**科幻海报的青蓝冷调是类型本体的视觉语法符号，绝非肖像出镜率不同所导致的统计假象。**
