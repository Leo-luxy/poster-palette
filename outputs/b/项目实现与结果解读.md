# 电影海报配色的类型结构与色型聚类：实现方法与结果解读

这份文档说明 B 组负责的「结构维度」怎样处理数据、怎样同时从**预设类型对比（做法 A）**与**无监督色型聚类（做法 B）**两条路径回答核心问题，以及如何正确阅读各张图表。完整统计表位于 `tables/`，一键复现步骤见 [复现说明](reports/复现说明.md)。

## 一、我们要回答什么问题

围绕「电影类型和海报配色之间有没有稳定的对应结构」，我们并行开展两项互补分析：

1. **预设类型对比（做法 A）**：先按电影原有的类型标签分组（重点考察科幻、爱情、恐怖三类，并扩展至样本量均超过 1,600 部的九类主流电影），比较它们的色相构成与明度、饱和度、色彩丰富度差异有多大。
2. **不预设类型的无监督聚类（做法 B）**：遮蔽所有类型、年份和国家信息，直接让算法根据海报自身的配色特征划分「客观色型」，检验数据自然聚成几类、每类长什么样，再回看不同电影类型在这些色型上的分布比例。

两项分析均以**单部电影**为基本统计单位，只读使用公共数据 `movies.csv`、`color_features.csv` 与 `movie_details.csv`（共匹配 19,694 部电影），不改动任何上游文件。

## 二、数据口径与多标签统计方法

### 1. 连续指标与色相的筛选边界

与全组口径一致：
- **明度（`mean_v`）、饱和度（`mean_s`）、色彩丰富度（`colorful`）**：使用全部 19,694 部有效记录。近灰或黑白海报的低饱和度与特定明度本身就是真实的视觉特征，不应剔除。
- **12 扇区色相分布（`h0`–`h11`）与色型聚类**：仅纳入满足 `sat_frac ≥ 0.10` 且色相向量有效的 **19,072 部**电影（排除 622 部近乎纯灰、色相角不稳定的海报）。计算组平均色相分布时，先确认每张海报的 12 扇区占比之和为 1，再对组内电影等权平均。

### 2. 多标签重叠样本的不确定性估计

TMDB 中一部电影通常带有 1—3 个类型标签（例如「科幻」与「恐怖」共享 588 部电影）。如果直接把各类型当作彼此独立的样本去拼列联表做常规卡方检验，同一部电影会被重复计数，违背观测独立性假设。

因此，B 组采用两套互补方案保证推断严谨：
- **主分析采用电影级联合重采样 Bootstrap（1,000 次）**：每次以整库的 19,694 部独立电影为抽样单元有放回抽取同等规模样本，在同一次重抽样本上同步计算两组均值之差（如「爱情减恐怖」或「科幻减全库」），取 2.5% 与 97.5% 分位数作为逐项 95% 置信区间。重叠电影在每次重抽中同步进出两组，其协方差被自然保留。
- **补充互斥子集的非参数检验**：在对比主讲三类（科幻、爱情、恐怖）时，额外提取只含其中一个标签、不含另外两个标签的 6,840 部严格互斥子集，执行 Kruskal-Wallis 检验并计算效应量 $\eta^2_H$（记入 `tables/sensitivity_checks.csv`），与联合 Bootstrap 结论相互印证。

## 三、做法 A：按类型分组看配色差异

结合 [类型配色结构图](../../figures/b/fig_q1_hue.png) 与 [类型预定对比图](../../figures/b/fig_q1_comparisons.png)，可以看到三点明确规律：

1. **明度是区分电影类型最强的单一维度**。九类主流电影按平均明度从高到低依次为：喜剧（0.631）、动画（0.608）、爱情（0.603）、剧情（0.534，贴近全库均值 0.538）、动作（0.493）、犯罪（0.490）、科幻（0.483）、惊悚（0.440）、恐怖（0.404）。爱情片比恐怖片平均亮 **0.199**（95% CI [+0.190, +0.208]），在互斥子集 Kruskal-Wallis 检验中效应量达 $\eta^2_H = 0.219$。
2. **色相分布体现清晰的冷暖分化，且并非单纯由人物肤色造成**。全扇区下，爱情片在 0°–60° 红橙黄波段平均占 54.2%，比科幻片（39.3%）高 **14.8 个百分点**；科幻片与动画片在 180°–240° 青蓝波段分别占 32.5% 与 32.1%，比爱情片（21.4%）高约 **11 个百分点**；恐怖片在 90°–150° 黄绿／绿波段（4.2%）高于爱情片（2.5%）。即便在每张海报内屏蔽 0°–60° 红橙黄（人脸肤色高发区）后对 60°–360° 重归一，科幻片的青蓝占比（46.8%）依然显著高于爱情片（39.9%）和恐怖片（35.2%），恐怖片的绿色占比（7.7%）也依然高于爱情片（6.1%）。
3. **饱和度与色彩丰富度凸显动画与喜剧的高彩特征**。动画片的平均饱和度（0.462）与色彩丰富度（79.80）均居首位；爱情片虽然明亮，但平均饱和度（0.381）反而略低于全库均值（0.401）与恐怖片（0.430），说明大量爱情片采用的是柔和浅亮配色而非高纯度浓烈涂抹。

读图提示：色相堆叠条中的 12 种颜色仅代表色相角度区间（与 C 组图面采用完全相同的色标），条段长度表示平均占比，不代表该类型的实际亮暗；亮暗与浓淡请看下方的指标均值与置信区间图。

## 四、做法 B：不预设类型的无监督色型聚类

### 1. 为什么要做圆锥色度变换

色相 `hue` 是首尾相接的角度（0° 与 360° 相邻），不能直接带入欧氏距离聚类。若仅把 `hue` 拆成 `cos(hue)` 与 `sin(hue)` 并分别标准化，一张几乎接近灰白（如 `mean_s = 0.12`）的海报与一张高纯度海报在色相方向上会获得相同权重。因此，我们采用 HSV 圆锥截面色度坐标：

$$c_x = \text{mean\_s} \cdot \cos(\text{hue}), \qquad c_y = \text{mean\_s} \cdot \sin(\text{hue})$$

与 `mean_v`、`mean_s`、`colorful` 组成五维特征 `Conic_5D`。当饱和度较低时，$(c_x, c_y)$ 自然收缩至原点附近；当饱和度较高时，暖色与冷色在圆周两端自然拉开。在 45 组候选评测中，`Conic_5D + K-Means (k=4)` 取得最低的 Davies-Bouldin 指数（1.1803）、最高的 Calinski-Harabasz 指数（7,213.5）以及 0.9913 的子样本重训 ARI 稳定性。

### 2. 四类客观色型与类型流向

结合 [色型聚类组合图](../../figures/b/fig_q1_cluster.png) 与 [典型海报抽象配色图](../../figures/b/fig_q1_palettes.png)：

- **明亮浅调（28.6%，5,464 部）**：高明度（0.712）、低饱和度（0.253），多见浅底留白或柔和暖浅色调；爱情片（41.1%）与喜剧片（39.6%）在此类占比最高。
- **浓烈暖调（25.9%，4,946 部）**：高饱和度（0.576）、高丰富度（92.1），0°–60° 红橙黄占比达 68.1%；动画片（32.9%）、动作片（29.2%）、喜剧片（28.5%）占比较高。
- **青蓝冷调（19.4%，3,704 部）**：高饱和度（0.537），180°–240° 青蓝占比达 57.8%；动画片（35.9%）与科幻片（30.8%）在此类明显富集。
- **深暗低彩（26.0%，4,958 部）**：低明度（0.330）、最低丰富度（38.7）；恐怖片（42.1%）、惊悚片（40.3%）、犯罪片（34.3%）集中于此，而动画片（10.3%）与喜剧片（12.1%）极少使用。

这说明：**海报配色并不是「一种电影类型对应一种专属颜色」，而是全行业共享四类基础视觉色型模板；所谓的「类型套路」，体现为不同类型对这四类色型的选择比例存在大幅倾斜。**

## 五、结论边界与局限

1. **连续光谱而非离散孤岛**：海报配色在特征空间中是连续过渡的（轮廓系数约 0.27），四类色型是对连续分布的概括性切分，边界附近的海报具有过渡特征。
2. **整幅统计不区分前景与背景**：现有特征对裁去底部 12% 后的整幅画面汇总，无法区分「暗背景上的亮色标题／人物」与「均匀中等明度画面」。
3. **样本代表性边界**：分析对象为 TMDB 收录且进入各年投票人数前 2.6% 的院线及热门影片原语言海报，结论描述的是该样本池内的类型配色关联，不能直接外推至全部未发行或极冷门影片，也不等同于观众审美偏好的因果证明。
