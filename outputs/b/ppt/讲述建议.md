# PPT 图面与建议讲述

建议在汇报中为「结构维度（类型配色与客观色型）」安排 3—4 页；典型配色页仅用于直观感受单片色块，定量结论以统计图面为准。

1. `fig_q1_genre_hue.png`：九类主流电影的平均色相构成存在系统性分化——爱情片 0°–60° 红橙黄占比达 54.2%（0°–30° 单扇区 38.3%），科幻片与动画片 180°–240° 青蓝占比分别达 32.5% 与 32.1%（较爱情片高约 11 个百分点），恐怖片在 90°–150° 黄绿／冷绿波段占比（4.2%）高于爱情片（2.5%）。色带仅纳入 `sat_frac ≥ 0.10` 的有效色相记录，展示色不代表实际明暗。
2. `fig_q1_genre_metrics.png`：采用半眼分布图同时展示组内影片核密度分布与组均值 95% CI——喜剧（0.631）、动画（0.608）、爱情（0.603）明显高于全库均值（0.538），科幻（0.483）、惊悚（0.440）、恐怖（0.404）依次走低，爱情片平均明度较恐怖片高出 0.199（联合 Bootstrap 95% CI [+0.190, +0.208]）；色彩丰富度以动画（79.8）和喜剧（72.1）最高。
3. `fig_q1_cluster.png`：不输入任何类型标签，在圆锥色度空间对 19,072 部海报无监督聚类得到四类客观色型——明亮浅调（28.6%）、浓烈暖调（25.9%）、青蓝冷调（19.4%）和深暗低彩（26.0%）。左侧二维主成分图以每张海报三主色面积加权融合色渲染并叠加核密度轮廓；右侧显示爱情与喜剧各有约 40% 落入明亮浅调，动画有 68.8% 集中在青蓝冷调与浓烈暖调，恐怖与惊悚各有超过 40% 落入深暗低彩。
4. `fig_q1_palettes.png`：上排展示四类无监督色型的组中心海报 14×10 连续色块与底部 7 主色比例条，下排展示动画、爱情、科幻、恐怖四类代表电影的组中心海报色块卡，帮助观众把统计数字还原为直观画面；每幅图简化自单张海报，不能替代整组分布。

口径提示：一部电影可含多个类型标签，跨组差值区间通过整库电影级联合重采样计算；样本受 TMDB 收录与每年票数前 2.6% 筛选约束，描述的是现有热门电影海报中的类型惯例。
