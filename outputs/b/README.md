# B：海报配色的类型结构与无监督色型聚类

本目录收纳 B 组的分析代码、统计表、解读报告、自动验收脚本及 16:9 PPT 图面。报告定稿图位于仓库的 `figures/b/`（同时在 `figures/fig_q1_hue.png` 保留一份主图以兼容交接文档路径）：`fig_q1_hue.png` 展示电影类型的色相构成与三项核心指标；`fig_q1_comparisons.png` 展示预定对比均值差与非肤色敏感性核验；`fig_q1_cluster.png` 展示无监督聚类选型、二维主成分分布与各类型的色型构成；`fig_q1_palettes.png` 展示四类客观色型与八类主流电影的中心海报抽象配色组合。

```text
outputs/b/
├── README.md               目录入口
├── run_manifest.json       输入 SHA-256 指纹、运行环境与参数配置
├── palette_manifest.json   典型海报选片与 8×10 色块抽象参数及指纹
├── 项目实现与结果解读.md   数据处理、双线方法原理、读图指南与结论边界
├── scripts/                类型结构、无监督聚类、抽象配色、绘图与自动验收脚本
├── tables/                 类型统计、联合 Bootstrap 对比、聚类基准与敏感性结果表
├── reports/                类型结论、聚类结论、复现说明及自动验收报告
└── ppt/                    四张 16:9 大字号汇报图面与逐页讲述建议
```

建议从 [类型配色结论](reports/类型配色结论.md)、[色型聚类结论](reports/色型聚类结论.md) 和 [PPT 讲述建议](ppt/讲述建议.md) 查看核心成果；完整数据表位于 `tables/`。可复现命令见 [复现说明](reports/复现说明.md)，逐项自动检查结果见 [验收报告](reports/validation_report.md)。

如需了解两套分析路线（预设类型分组对比 vs 不预设类型的无监督色型聚类）、多标签联合重采样方法以及图面读法，可先阅读 [项目实现与结果解读](项目实现与结果解读.md)。
