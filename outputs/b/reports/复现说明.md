# 复现说明

从仓库根目录运行，需安装 Python、numpy、pandas、scipy、scikit-learn、matplotlib、Pillow；脚本只读访问 `data/`，不安装依赖，也不发起网络请求。若公共数据文件的 SHA-256 指纹发生变化，脚本会主动报错中止，需核实数据版本后再更新 `run_manifest.json`。

```bash
python outputs/b/scripts/b01_genre.py
python outputs/b/scripts/b02_cluster.py
python outputs/b/scripts/b03_palettes.py
python outputs/b/scripts/b04_plots.py
python outputs/b/scripts/b99_validate.py
```

## 1. 口径与方法摘要

- **样本范围**：1950—2025 年全部匹配到配色特征的 19,694 部电影（`movies.csv` 与 `color_features.csv` 按 `id == tmdb_id` 一对一连接，其中 4 部无类型标签记录记入 `tables/missing_genres.csv`）。
- **指标与近灰过滤**：明度（`mean_v`）、饱和度（`mean_s`）、色彩丰富度（`colorful`）保留全部有效记录；色相分布与无监督色型聚类严格限定 `sat_frac ≥ 0.10` 且色相有效的 19,072 部电影，色相占比先按单张海报归一再按电影等权平均。
- **多标签不确定性估计**：一部电影可同时含多个类型标签（如「科幻｜恐怖」）。为避免把重叠样本拆成独立组导致伪重复计数，所有跨类型对比与「某类型减全库均值」统一采用**按电影独立有放回重采样 1,000 次的联合 Bootstrap**（每次重抽整库电影后同步计算两组差值），报告逐项 95% 百分位区间。此外，在 `tables/sensitivity_checks.csv` 中补充了剔除重叠影片后的严格互斥三组 Kruskal-Wallis 检验结果。
- **无监督色型聚类**：在 19,072 部色相有效海报上构造 HSV 圆锥色度特征 `[mean_v, mean_s, colorful, mean_s·cos(hue), mean_s·sin(hue)]`，标准化后执行 K-Means（`k=4`，`seed=42`，`n_init=20`）。低饱和海报的色度分量自然收敛至原点附近，避免了对微弱色相角赋予过高权重。

## 2. 典型海报抽象配色图

`b03_palettes.py` 生成报告图 `figures/b/fig_q1_palettes.png`、16:9 汇报图 `outputs/b/ppt/fig_q1_palettes.png` 及选片记录表 `outputs/b/tables/palette_examples.csv`。每组在满足 `sat_frac ≥ 0.10` 的样本中（非动画类型排除带「动画」标签的合集片），按「三项指标相对组内中位数的四分位距标准化平方距离均值 + 单片色相向量与组平均色相向量的总变差距离平方」排序，选取距离最小且未在同版展示中重复出现的海报。

抽象化步骤：裁去海报底部 12%，缩放至 120×168 并轻度抗锯齿（$\sigma=1.0$，避免大核 RGB 模糊将互补色混为灰褐）后，以确定性 `KMeans(k=7, seed=42)` 提炼 7 种真实主色，再在类别指示掩膜上平滑并归纳为 14×10 方形网格，在每幅色块图下方附等宽的 7 主色面积比例条。每幅图仅是单张中心海报的简化示意，不能替代整组统计分布。
