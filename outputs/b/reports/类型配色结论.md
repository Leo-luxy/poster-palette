# 电影类型配色差异：结果与口径

1950—2025 年全部匹配到配色特征的 19,694 部电影海报中，不同电影类型的色相构成及明度、饱和度、色彩丰富度存在清晰且稳定的差异。在主讲三类预定对比中，爱情组相对恐怖组的平均明度高 0.1990（逐项 95% CI +0.1902 至 +0.2078，相当于全库标准差的 0.90 倍），平均饱和度低 0.0483（−0.0576 至 −0.0391），平均色彩丰富度高 6.90（+5.38 至 +8.23）；爱情组相对科幻组的平均明度高 0.1200（+0.1102 至 +0.1295），0°–60° 红橙黄波段平均占比高 14.83 个百分点（+13.23 至 +16.39），而 180°–240° 青蓝波段低 11.09 个百分点（−12.60 至 −9.55）。扩展到九类主流电影后，明度从喜剧（0.6305）、动画（0.6082）、爱情（0.6034）依次降至科幻（0.4835）、惊悚（0.4401）和恐怖（0.4044）；色彩丰富度以动画（79.80）和喜剧（72.09）最高，惊悚（53.92）和恐怖（55.58）最低。

一部电影可同时包含多个类型标签（例如科幻与恐怖重叠 588 部）。为避免把重叠样本拆成独立组导致伪重复计数，所有对比统一采用按整库电影独立有放回重采样 1,000 次的联合 Bootstrap 估计均值差及逐项 95% 区间。若剔除同时含科幻、爱情、恐怖中两个及以上标签的重叠影片，在严格互斥的 6,840 部子集上执行 Kruskal-Wallis 检验，三项指标同样呈现明确差异：明度 $H = 1501.1$（$p < 10^{-300}$，$\eta^2_H = 0.2193$）、饱和度 $H = 161.5$（$p = 8.7 \times 10^{-36}$，$\eta^2_H = 0.0233$）、色彩丰富度 $H = 164.8$（$p = 1.6 \times 10^{-36}$，$\eta^2_H = 0.0238$），其中明度是区分类型最强的单一指标。

## 2. 肤色扇区屏蔽与近灰阈值敏感性

由于各类型海报在 0°–60° 红橙黄区间占比均较高（含人物面部肤色与暖色灯光），我们在每张海报内屏蔽 `h0`、`h1`（0°–60°）并对剩余 60°–360° 扇区重归一（保留剩余色相份额 ≥ 5% 的海报）。重归一后，科幻组在 180°–240° 青蓝区间平均占 46.82%，仍高于爱情组（39.89%，差值 +6.93 个百分点，95% CI [+5.06, +8.82]）与恐怖组（35.19%，差值 +11.63 个百分点，[+9.93, +13.32]）；恐怖组在 90°–150° 黄绿／绿区间占 7.72%，仍高于爱情组（6.08%，差值 +1.64 个百分点，[+0.87, +2.32]）。此外，将近灰过滤阈值在 `sat_frac ≥ 0.05` 至 `0.20` 间扫描，上述三项色相波段差值的变化幅度均不超过 0.3 个百分点（详见 `tables/sensitivity_checks.csv`）。
