## 结论

队友只需要 `common.py`。其余脚本的结果都已经落盘在 `data/` 下，
他们直接读 CSV 就行，不用跑任何脚本。

`01_fetch.py` 是采集脚本，**不用发给队友**——它依赖 API key，
而且数据已经采完了。留着是为了报告里能说清"数据怎么来的"，
以及将来要补数据时重跑。
