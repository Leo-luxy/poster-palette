# 海报会说话——四十年电影配色里的类型密码

> 数据分析实践 · 课程大作业

**一句话**：用 14,662 部电影的海报配色，从**结构、时间、空间**三个角度回答「什么是流行、什么是套路」。

---

## 这个仓库是什么

一条可复用的流水线：采集 → 特征 → 图 → 成稿。每一层的产物都落在仓库里，下一层直接读，
不用重跑上游。

```
TMDB API  ──►  movies.csv  ──┐
海报 jpg  ──►  color_features.csv ──┴──►  图 1~4  ──►  报告 / PPT
```

队友打开就能看最新进度，不需要装环境，也不需要 API key。

## 可以挖的方向（不预先锁死）

**① 结构：类型和颜色有没有稳定的对应？**

- 做法 A：先按类型分组（科幻 / 爱情 / 恐怖…），比较配色分布
- 做法 B：不预设分组，直接对海报配色聚类，用肘部法 / 轮廓系数挑合适的 k，
  看数据自己分出几类「色型」，再回头看这些色型和真实类型重合多少

两种都能独立成图，也可以都做——B 做出来的 k 如果和三类对不上，本身就是结论。

**② 时间：四十年里配色怎么变？**

整体在变暗、变「收」（明度 1960s 0.61 → 2020s 0.50）。
分类型看会更复杂，值得单独拆。

**③ 空间：不同国家的海报能不能看出差异？**

现成可用的代理是 `original_language`：英语 10,764（73%）、法语 1,107、意大利语 636、
日语 496、西班牙语 370、韩语 187、中文 227。样本量够做 5–6 个语种的对比。

想要真正的国家维度，得补 `production_countries` 字段（见下节成本）。

**④ 效用：颜色和口碑有关系吗？**

已经做过一版：没有。相关系数全部落在 ±0.08 以内（图 3）。
如果换别的因变量（比如票房、评分人数），可能还有别的故事。

## 扩展成本（想加东西先看这里）

| 想加什么 | 怎么做 | 成本 |

## 协作：每人一条分支，直接 push

`main` 受保护，谁都不能直接推；每人有自己的分支，改完推自己的，A 点一下合并。

| 分支 | 谁 | 只改这些 |
| --- | --- | --- |
| `feat/b` | B | `figures/fig_q1_*.png`、`outputs/b/` |
| `feat/c` | C | `figures/fig_q2_*.png`、`figures/fig_q4_*.png`、`outputs/c/` |
| `feat/d` | D | `docs/报告.*`、`docs/汇报.*`、`outputs/d/` |
| `main` | A | `data/`、`scripts/`、`README.md` |

推自己的分支永远不会被拒，也不会影响别人——四个人改的是不同文件，物理上撞不上。
`data/` 是只读的，缺字段找 A。

完整的点法（GitHub Desktop 每一步点哪、常见报错怎么办）见
[`docs/协作流程`](docs/协作流程.md)，**第一次动手前花 5 分钟看一遍**。
