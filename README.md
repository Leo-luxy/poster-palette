# 海报会说话——四十年电影配色里的类型密码

> 数据分析实践 · 课程大作业

**一句话**：用 14,662 部电影的海报配色，回答「类型能不能用颜色区分、配色四十年怎么变、颜色能不能预测口碑」。

---

## 这个仓库是什么

课程大作业的共享工作区：数据、代码、图、文档都放在这里，队友打开就能看最新进度，
不需要装任何东西，也不需要 API key。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `data/movies.csv` | 14,662 部电影元数据（1950–2025，TMDB） |
| `data/color_features.csv` | 14,657 张海报的配色特征（饱和度 / 明度 / 色相 / 主色） |
| `data/yearly*.csv` | 年度聚合表，做趋势图直接读 |
| `data/posters/` | 14,657 张海报原图，342×512，共 716 MB |
| `figures/` | 定稿图（目前有图 3） |
| `docs/` | 交接文档、数据字典 |
| `scripts/` | 处理脚本 |

TMDB API，`vote_count ≥ 200`，1950-01-01 至 2025-12-31，采集于 **2026-11-02**。
