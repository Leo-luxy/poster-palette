## 3. B：图 1（色相分布）+ 统计检验

### 目标

回答「海报的配色结构是什么」。

**两条路，选一条或都做**：

- **预设分组**：按科幻 / 爱情 / 恐怖分组，比较 12 扇区色相分布（下面按这条写）
- **不预设**：直接对所有海报的配色特征聚类，用肘部法或轮廓系数挑 k，
  看数据自己分出几类「色型」，再回头看和真实类型重合多少。
  这条路输出的 k 如果对不上三类，本身就是个结论。

选第二条时 `data/color_features.csv` 已经够用，注意 `hue` 要先转 sin/cos 再进 K-Means。

### 起点代码

```python
import numpy as np
import matplotlib.pyplot as plt

for g in ['科幻', '爱情', '恐怖']:
    share = common.hue_share(df, g)          # 12 个扇区的占比，已归一
    print(g, share.round(3).tolist())
```

### 图怎么画

- 横轴：12 个扇区（0–30°、30–60°…），标注「0°=红 120°=绿 240°=蓝」
- 纵轴：占比
- 三类并排的分组柱状图（不要用极坐标叠加，会看不清，我试过）
- 配色用 `common.COLOR['科幻']` 等，保证和别的图一致

### 检验

| 检验什么 | 用什么 |
| --- | --- |
| `mean_v`、`mean_s`、`colorful` 在三类间是否有差异 | Kruskal-Wallis（`scipy.stats.kruskal`） |
| 12 扇区分布是否独立于类型 | 卡方检验（`scipy.stats.chi2_contingency`） |

### 验收标准

1. 图里能一眼看出「科幻偏蓝、恐怖偏绿」；
2. 检验表有 H 值 / p 值，并在正文写一句人话解释；
3. **不要**只写「p<0.001 差异显著」就完事——要写差多少（比如「明度相差 0.25，是三类里最大的一项」）。

### 坑

`common.hue_share` 内部已经过滤了 `sat_frac < 0.1`。**自己写的话别忘**，391 张灰海报会毁掉分布。

## 4. C：图 2（年代趋势）+ 图 4（色型聚类）

### 图 2 目标

回答「四十年里，同类型的配色怎么变」。

### 起点：别自己 groupby，直接读聚合表

```python
import pandas as pd
y = pd.read_csv('data/yearly.csv')                     # 每年：n, med_s, med_v, med_colorful, med_vote
byg = pd.read_csv('data/yearly_by_genre.csv')          # 每年 × 类型
print(byg[byg.genre == '恐怖'].head())
```

### 画法

- 折线图，三类各一条，横轴年份、纵轴 `med_v`（或 `med_colorful`）
- **样本量 < 30 的年份不画点**（`common.MIN_CELL`），否则早期年份的抖动全是噪声
- 图下方标注 `n=?` 或者用透明度表示样本量

### 图 2 的结论方向（数据已经指出来了，你去验证）

我先把分类型的年代中位数算了一遍（按样本量加权），三条线都真实存在：

| 十年 | 1950s | 1970s | 1990s | 2010s | 2020s |
| --- | --- | --- | --- | --- | --- |
| 恐怖 · 明度 | 0.52 | 0.42 | **0.32** | 0.37 | 0.34 |
| 爱情 · 明度 | 0.65 | 0.70 | 0.60 | 0.63 | 0.57 |
| 科幻 · 明度 | 0.59 | 0.51 | 0.43 | 0.47 | 0.48 |

**能写的**：恐怖片明度从 1950s 的 0.52 一路降到 1990s 的 0.32（降幅 38%），之后在 0.34–0.37 之间横盘；爱情片同期只从 0.70 降到 0.57，而且始终比恐怖片亮 0.2 以上。

**不能写的**：饱和度和色彩丰富度**没有**单调趋势（恐怖片 2020s 的饱和度甚至回升到 0.49）。
早期 300 张试跑时我以为「恐怖片去饱和」，扩到 1.4 万张后这个结论不成立——**不要写进报告**。
这类「试跑成立、全量推翻」的情况，本身就是报告「讨论」部分可以写的素材。

### 图 4 目标

不预设类型，让数据自己把海报分成几种「色型」。

### 做法

1. 特征选 4–6 个：`mean_v`、`mean_s`、`colorful`、`hue`（转成 sin/cos 两个）、`h7`（蓝）。
   **注意 `hue` 是角度，必须先转 `sin`/`cos` 再进 K-Means**，否则 0° 和 359° 会被当成两极。
2. 先 `StandardScaler` 标准化，再 `KMeans(k=4~6)`，用肘部法或轮廓系数选 k。
3. 出两张图：聚类结果的 2D 散点（PCA 降到 2 维）+ 每个色型在「类型 / 年代」上的占比堆叠图。
4. 给每个簇起个中文名（比如「高饱和暖调」「暗黑冷调」），报告里要用。

### 验收标准

1. 图 2 的每条线都有 n 标注，早期稀疏年份没画；
2. 图 4 的每个簇有人话名字，不是「簇 0」；
3. 两张图都能用一句话说出结论。

### 坑

- **多标签会让样本重复计数**：做类型对比时用 `common.has_genre`，不要按 `genre_ids` 精确匹配字符串。
- 趋势图和聚类图都要跑一遍 `sat_frac` 敏感性分析（过滤前后结论是否一致），写进附录。

### 也可以换成空间维度

不做年代趋势，改做「不同国家 / 地区的海报有没有差异」，做法和口径跟上面一样，只是分组变量变了。

- **真国家数据已经有了**：`data/movie_details.csv` 里的 `production_countries`，
  用 `common.has_country(df, 'JP')` 取子集，不用再找 A 补
- 头部样本：美国 9,767、英国 2,076、法国 1,984、意大利 954、德国 889、加拿大 844、
  日本 655、西班牙 453、比利时 413、香港 259、中国大陆 250
- 想用语言当代理也行：`original_language` 英语 10,764、法语 1,107、意大利语 636
- **两者别混用**：`production_countries` 是资方/制片地，`original_language` 是原始语言。
  法国制片但英语对白的片，两边归属不同，报告里说清用的是哪个

推荐对比组合（样本量都不低于 250）：**美国 vs 日本 vs 法国 vs 中国大陆**，
或者**好莱坞（US）vs 非好莱坞**两组，后者样本更均衡、结论也更稳。

二选一就行，不必都做。

## 6. 六条通用规矩

1. **`data/` 只读**。要存中间结果放 `outputs/`，别覆盖原表。
2. **`id` 必须按 int 读**：`pd.read_csv(..., dtype={'id': int})`，否则 merge 时会因为字符串/整型对不上而丢行。
3. **色相统计前必须 `sat_frac ≥ 0.10`**（用 `common.usable_hue`）。
4. **多标签不要精确匹配**，用 `common.has_genre`。
5. **p 值小 ≠ 关系强**。n=1.4 万时 r=0.05 也会 p<0.001。图 3 已经踩过这个坑，写结论请报效应量。
6. **中文乱码**：每个画图脚本开头加
   ```python
   plt.rcParams['font.sans-serif'] = ['PingFang SC', 'Arial Unicode MS']
   plt.rcParams['axes.unicode_minus'] = False
   ```

## 8. 卡住了先看这里

| 症状 | 原因 / 解法 |
| --- | --- |
| `KeyError: 'id'` | 读 csv 没加 `dtype={'id': int}`，或路径不对（要先 `cd 大作业`） |
| 中文变方块 | 没设 `font.sans-serif`，见第 6 节第 6 条 |
| merge 后行数变多 | 有重复 `id`（不该发生）；或你在按 `genre_ids` 直接匹配 |
| 图里早期年份乱跳 | 样本太少，按 `common.MIN_CELL` 过滤 |
| 色相图整体偏红 | 人脸肤色，做一次剔除 10–40° 的敏感性分析 |
| matplotlib 报缓存错误 | 无害，`common.py` 已设 `MPLCONFIGDIR`；自己写脚本时加 `os.environ['MPLCONFIGDIR']='/tmp/mpl'` |
